# Learning Method

## Daily Loop

1. **Concept** — understand the minimum theory needed.
2. **Implement** — build the important mechanism yourself.
3. **Experiment** — change one assumption and observe what happens.
4. **Explain** — write a short explanation in your own words.
5. **Ship** — commit code, notes, and results to GitHub.

Typical session:
- 20–30 min concept
- 45–60 min implementation
- 15–30 min experiment
- 10 min notes + commit

## Definition of Done

A topic is not complete because a video or course chapter was finished. It is complete when most of these are true:
- I can explain it without framework jargon.
- I can implement a small version.
- I can identify common failure modes.
- I ran at least one meaningful experiment.
- I can connect it to a real AI system.
- There is evidence in GitHub.

## Commit Style

Prefer:
- `feat: implement scalar autograd engine`
- `test: compare gradients against pytorch`
- `experiment: compare activation functions`
- `docs: explain chain rule through computation graph`

Avoid: `update`, `changes`, `done`.

## Learning Log

For each session record:
- Learned
- Built
- Experimented
- Still unclear
- Next
