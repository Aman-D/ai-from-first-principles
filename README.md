# AI From First Principles

A learn-by-building journey to understand, train, evaluate, deploy, and operate modern AI systems.

## North Star

Be able to explain important model internals from first principles **and** build production-grade AI systems suitable for Senior AI / GenAI engineering roles.

## Method

**Understand → Implement → Experiment → Explain → Apply → Ship**

Watching or reading alone does not count as completion.

## Current Status

- Current phase: Phase 0 — Foundations & environment
- Current milestone: Neural Networks from First Principles
